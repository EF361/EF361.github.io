# Monthly Portfolio Update

Runs on day 1 of each month. Owner answers, Claude drafts, owner approves. Nothing goes live without approval.

## Steps
1. Ask the 6 questions below, one mini-project at a time.
2. Fill `content/<id>.json` from the template. Never invent numbers. If unknown, leave the block out.
3. Ask for 1 to 3 images (screenshot, mock-up, short GIF). Replace old preview images if they look outdated.
4. Check the live link still works and the screenshot is current.
5. Commit on a branch. Show the diff. Push only after the owner says yes.

## The 6 questions
1. What did you make this month, and what type is it (game, tool, AI, automation)?
2. What was the problem or goal? Who is it for?
3. What exactly did you do? Did anyone help (credit them)?
4. How did you build it? What did you try that did not work?
5. Any numbers or feedback? (users, time saved, speed, scores, comments)
6. Which images or live demo should visitors see?

## Confidentiality check (always)
- Client or company names (for example JJ Deco, Meta AI): ask permission before naming.
- Private repos: link only if the owner agrees.
- No personal data, keys or real customer screenshots.
